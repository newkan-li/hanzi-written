# 1. 总览

上线分五步：**准备账号与资质 → 本地化数据源 → 代码/域名配置 → 体验与真机验证 → 提审发布**。本文给出每一步的操作与检查项。

# 2. 账号与资质

1. 在微信公众平台注册小程序，拿到自己的 **AppID**。
   - 个人主体可免费注册；企业/组织认证 300 元/年。
2. 选择**类目**：
   - 本小程序定位为「练字/笔顺查询工具」。尽量选**工具类**类目，规避教育类（K12 学科培训）资质门槛。
   - 类目以微信后台**最新**目录为准；若被要求教育资质，可调整定位描述。
3. 在「开发 → 开发管理 → 开发设置」抄录 **AppID**，替换项目里的占位。

# 3. 数据源本地化（最重要）

开发期笔画数据来自 `cdn.jsdelivr.net`，**国内访问不稳定**，正式上线必须换。

## 3.1 笔画数据

1. 批量下载教材汉字笔画数据（Node 18+，无需依赖）：

   ```bash
   node tools/fetch-strokes.mjs --out ./dist-strokes
   ```

   产出 `dist-strokes/<字>.json`（约 3000 个文件）。

2. 上传到国内可达的静态存储：微信**云开发存储**、腾讯云 **COS**、阿里云 **OSS** 或自建 CDN。
3. 修改 `utils/config.js`：

   ```js
   charDataCDN: 'https://your-bucket.cos.ap-guangzhou.myqcloud.com/hanzi-data'
   ```

4. 把该域名加入**request 合法域名**。

> 客户端缓存：`utils/charData.js` 已做「内存 → 本地文件 → 远程」三级缓存，练过的字离线可复用。

## 3.2 朗读音源

- `utils/config.js` 的 `tts.sources` 为**多音源数组**（自动降级），默认使用公开 TTS，可能不稳或被拦截。
- 上线建议：替换为自有 TTS 服务，或改用「微信同声传译」插件；不需要朗读则设 `tts.enabled = false`。
- 若使用默认公开音源，需把 **`fanyi.baidu.com`、`dict.youdao.com`** 加入 request 合法域名。

## 3.3 教材/古诗/成语数据

- 已内置在 `data/`（`textbook.js`、`textbookPinyin.js`、`poems.js`、`idioms.js`、`charInfo.js`），**无需网络**。

# 4. 代码与项目配置

## 4.1 project.config.json

- `appid`：替换为正式 AppID。
- 上线前确认 `setting.urlCheck` 行为：正式发布需要在后台配置合法域名，并在开发者工具取消「不校验合法域名」。

## 4.2 utils/config.js 快速开关

| 项 | 说明 |
| --- | --- |
| `charDataCDN` | 笔画数据基地址（改成自己的存储域名） |
| `tts.enabled` | 是否启用朗读（合规/无网环境可关闭） |
| `tts.url` | 朗读音源 |
| `app.version` | 关于页展示版本号 |

## 4.3 隐私保护指引

- 在公众平台「设置 → 服务内容声明 → 用户隐私保护指引」按实际填写：
  - 本小程序**不收集个人身份信息**；
  - 使用到**相册权限**（保存字帖/海报/作品到相册）；
  - 使用**网络**下载笔画数据。
- 小程序内「我的 → 关于与隐私」页已内置隐私说明。

## 4.4 订阅消息（打卡提醒）

小程序端只能**申请授权**，**真正的定时推送必须由服务端发送**。

1. 公众平台「功能 → 订阅消息 → 选用模板」申请一个「打卡提醒」类模板，得到 **模板ID**。
2. 在 `utils/config.js` 填写：

   ```js
   subscribe: { enabled: true, tmplId: '你的模板ID' }
   ```

3. 小程序「我的 → 打卡提醒」开关会调用 `wx.requestSubscribeMessage` 申请授权，并保存提醒时间。
4. 服务端定时发送（示例：微信云开发云函数 + 定时触发器）：

   ```js
   // cloudfunctions/sendReminder/index.js
   const cloud = require('wx-server-sdk')
   cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })
   exports.main = async () => {
     const db = cloud.database()
     const users = await db.collection('remind').where({ on: true }).get()
     for (const u of users.data) {
       try {
         await cloud.openapi.subscribeMessage.send({
           touser: u._openid,
           templateId: '你的模板ID',
           page: 'pages/index/index',
           data: { thing1: { value: '该练字打卡啦' }, time2: { value: u.time } }
         })
       } catch (e) { /* 忽略 */ }
     }
   }
   ```

   ```json
   // cloudfunctions/sendReminder/config.json
   { "triggers": [{ "name": "daily", "type": "timer", "config": "0 0 20 * * * *" }] }
   ```

5. 注意：订阅消息为**一次性授权**，发送一次即消耗一次授权；需在用户每次使用小程序时引导再次订阅。

> 若不引入服务端，则「提醒」开关仅作本地记录，不会真正推送。

# 5. 包体与性能

- 主包默认包含：`vendor/`（hanzi-writer ~106KB）、`data/`（教材/古诗等约 110KB）、页面代码。整体远低于主包 2MB 上限。
- 若后续体积增大，可把 `data/textbook*.js`、`data/poems.js` 移入分包（注意：移到分包后，**首页将无法直接读取**，需要改为预取或摘要方案）。
- 字库/教材等大数据**不要内置全量笔画数据**（全量十几 MB），始终走 3.1 的自建存储 + 按需缓存。

# 6. 体验与真机验证

- 上传**体验版**，用微信扫码在真机验证：
  - 练字动画、描红、测验
  - 教材同步 / 听写 / 测试卷 / 古诗
  - 字帖、海报的保存到相册（真机才准）
  - 断网后重进已练字仍可显示（缓存）
  - 真机 Console 无红色错误

# 7. 提审与发布

1. 开发者工具「上传」，填版本号与备注。
2. 公众平台「版本管理 → 提交审核」，填写功能说明。
3. 审核注意：
   - 内容合规、无诱导分享/关注；
   - 字表/古诗为公共领域或已授权内容（见第 8 节）；
   - 隐私指引与权限一致。
4. 审核通过后「发布」。
