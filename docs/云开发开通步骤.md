# 0. 前置说明

- **哪些我做完了**：所有代码（云存储字库分支、云同步、云函数文件、配置开关、工具脚本）都已内置，默认关闭、不影响本地功能。
- **哪些需要你操作**：开通云开发、上传文件、建集合、部署云函数、申请模板——这些绑定你的账号，无法代做。
- 需要一个**真实的小程序 AppID**（游客/测试号不能用云开发）。

# 1. 开通云开发 & 创建环境

1. 微信开发者工具打开本项目。
2. 点顶部工具栏 **「云开发」** 按钮 → 同意开通。
3. 新建环境，填名称（如 `moxue`），等待创建完成。
4. 在环境概览里**复制「环境ID」**（形如 `moxue-1a2b3c`）。

# 2. 填配置

编辑 `utils/config.js`：

```js
cloud: {
  enabled: true,
  env: '你的环境ID',
  charDataRoot: '', // 第 3 步上传后回填
  sync: true
}
```

# 3. 上传笔画数据到云存储

1. 本地生成数据（Node 18+）：

   ```bash
   node tools/fetch-strokes.mjs --out ./dist-strokes
   ```

   产出 `dist-strokes/<字>.json`（约 3000 个文件）。

2. 云开发控制台 → **存储** → 新建文件夹 `hanzi-data` → 进入后**上传**（可多选整个文件夹，建议分批）。

   > 批量上传（可选，用 CLI）：`npm i -g @cloudbase/cli` → `tcb login` → 在云开发控制台获取环境ID后：
   > `tcb storage upload dist-strokes --env 你的环境ID -c hanzi-data`

3. 进入 `hanzi-data` 目录，复制任一文件的 **fileID 前缀**（到目录名为止），形如：

   ```
   cloud://moxue-1a2b3c.xxxx/hanzi-data
   ```

4. 回填到 `utils/config.js` 的 `cloud.charDataRoot`。

完成后，练字时字库将走 `wx.cloud.downloadFile`（**免 request 域名白名单**）。

# 4. 建数据库集合（云同步）

云开发控制台 → **数据库** → 新建集合：

| 集合 | 用途 | 权限 |
| --- | --- | --- |
| `hw_data` | 记录/收藏/生字本/学习记录/偏好 | **仅创建者可读写** |
| `remind` | 打卡提醒设置 | **仅创建者可读写** |

> 「仅创建者可读写」会按 `openid` 自动隔离，每个用户只能读写自己的数据。

完成后，进入小程序「我的 → 云同步数据」即可同步。

# 5. 部署云函数（打卡提醒推送）

1. 编辑 `cloudfunctions/sendReminder/index.js`，把 `TEMPLATE_ID` 换成你的模板ID（见第 6 步）。
2. 开发者工具里右键 `cloudfunctions/sendReminder` → **上传并部署（云端安装依赖）**。
3. `config.json` 已含**定时触发器**（每天 20:00，cron `0 0 20 * * * *`），部署后在云开发控制台「云函数 → 触发器」确认。
4. 若工具提示找不到云函数目录：在 `project.config.json` 增加 `"cloudfunctionRoot": "cloudfunctions/"`。

# 6. 申请订阅消息模板

1. 公众平台 → **功能 → 订阅消息 → 选用模板**，选一个「打卡提醒」类模板（含两个字段，如「事项」+「时间」）。
2. 复制**模板ID** → 填入两处：
   - `utils/config.js` 的 `subscribe = { enabled: true, tmplId: '模板ID' }`
   - `cloudfunctions/sendReminder/index.js` 的 `TEMPLATE_ID`

> 云函数的字段名（`thing1`、`time2`）需与你所选模板的字段一致，按需修改。

# 7. 验证

1. **字库走云**：进练字页，控制台应看到 `wx.cloud.downloadFile`，且不再依赖 CDN 域名。
2. **云同步**：我的 → 云同步数据 → 换一台设备/清缓存后同步，数据回来。
3. **打卡提醒**：我的 → 打卡提醒开关 → 授权；到设定时间（或手动在控制台**测试云函数**）应收到订阅消息。

# 8. 成本提示

- 云开发按量计费，有免费额度/新用户体验；个人练手用量很小，通常每月几元内。
- 具体额度与价格以**微信云开发官方价格页**为准。
